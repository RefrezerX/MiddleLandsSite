# Сайт MiddleLands

Статический сайт-визитка сервера: главная страница и гайды по механикам. Собирается скриптом на Python в папку `docs/`, которую публикует GitHub Pages. Сервер и база данных не нужны.

## Что где лежит
| Путь | Что это |
|---|---|
| `content.py` | **Все тексты**: описание сервера, земли, привилегии, ссылки, 15 гайдов |
| `build.py` | Сборщик страниц (только стандартная библиотека Python) |
| `assets/style.css`, `assets/main.js` | Оформление и скрипт (копирование IP, меню, угли на главной) |
| `img/` | Ваши фото — список в `PHOTOS.md` |
| `docs/` | Готовый сайт. Генерируется, руками не править |

## Как обновить сайт
1. Поправьте тексты в `content.py` или положите фото в `img/`.
2. Запустите `python build.py` (Python 3.8+).
3. Посмотреть локально: откройте `docs/index.html` в браузере.
4. Отправьте изменения на GitHub (`git add . && git commit -m "обновление" && git push`).

## Публикация на GitHub Pages (один раз)
1. Создайте публичный репозиторий, например `middlelands-site`, и загрузите туда содержимое этой папки.
2. Settings → Pages → Build and deployment → Source: **Deploy from a branch**, Branch: **main**, папка **/docs** → Save.
3. Через минуту сайт будет доступен по адресу `https://<ваш-ник>.github.io/middlelands-site/`.
4. Впишите этот адрес в `content.py` → `SITE["url"]` и пересоберите — тогда заработает превью ссылок.

Свой домен: Settings → Pages → Custom domain, у регистратора добавьте CNAME на `<ваш-ник>.github.io`.

## Добавить гайд
Скопируйте любой блок в списке `GUIDES` в `content.py`, поменяйте `slug` (латиницей — это имя страницы), заголовок и разделы. Плитка на главной и пункт в меню появятся сами. Размер плитки: `big`, `wide` или `normal`.

Разметка в текстах: `**жирный**`, `` `/команда` ``, `[ЛКМ]` / `[ПКМ]` / `[F]` / `[Shift]` — клавиши.
